Student Grade Manager
A lightweight Python CLI application designed to manage student academic records, calculate subject averages, and track pass/fail performance.

Overview
This program provides an interactive terminal interface for managing student grades. It allows users to store multiple student profiles, compute overall average scores automatically, and look up individual academic summary reports.

Features
Record Management: Add new student profiles along with individual subject scores.

Automated Calculation: Automatically computes the average grade upon student entry.

Academic Evaluation: Determines passing or failing status based on total average threshold.

Data Lookup: Search and view comprehensive reports for specific students.

Student Directory: View a list of all currently registered student profiles.
